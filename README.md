## Features
- **Dashboard Overview:** Track your consistency streaks, algorithmic acceptance rate, and FAANG level readiness prediction (e.g. Meta E6 / Google L6).
- **IDE & AI Solver:** A dedicated space for tackling complex algorithmic problems (e.g., Trapping Rain Water) with integrated AI Co-Pilot for runtime, space complexity analysis, and logic mentoring.
- **System Design Simulator:** Interactive visual topology modeling for distributed systems, complete with an AI interviewer giving pushback and evaluating your architectural trade-offs.
- **Behavioral STAR Method:** Prepare for leadership and behavioral rounds using the STAR framework.

## Tech Stack
- **Framework:** Next.js (App Router, Turbopack)
- **Styling:** Tailwind CSS v4 (Custom Dark Theme variables)
- **Typography:** Geist & JetBrains Mono
- **Icons:** Material Symbols Outlined

1. Clone the repository
2. Run \
pm install\
3. Run \
pm run dev\
4. Open [http://localhost:3000](http://localhost:3000)

## Design System
The UI implements a custom dark theme using deeply integrated Tailwind configuration variables, focusing on high-contrast, accessible, and sleek developer-friendly aesthetics.
